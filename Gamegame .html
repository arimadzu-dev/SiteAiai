1. Архитектурные Паттерны ИИ

Сравнение основных фундаментальных систем принятия решений NPC в индустрии GameDev.

Базовый уровень

Конечные Автоматы (FSM)

Набор фиксированных состояний (Idle, Patrol, Chase, Attack) и условий переходов. Идеально для простых врагов и боссов первой волны.

  • ✔ Минимальные затраты CPU
  • ✔ Простая реализация в пару классов
  • ✖ "Спагетти-код" при превышении 10+ состояний
Стандарт Индустрии

Деревья Поведения (Behavior Trees)

Иерархическое дерево с узлами типа Sequence, Selector, Parallel и Action. Используется в Unreal Engine и Unity (Behavior Designer / NodeCanvas).

  • ✔ Высокая модульность и переиспользование
  • ✔ Наглядный визуальный граф
  • ✖ Требует аккуратного менеджмента состояния
Продвинутый

GOAP (Goal-Oriented Action Planning)

NPC генерирует план действий из текущего состояния мира в целевое, используя алгоритмы поиска A* в пространстве состояний.

  • ✔ Динамическое и естественное поведение
  • ✔ Легко добавлять новые действия без переделки кода
  • ✖ Повышенная нагрузка на процессор
Симуляторы Жизни

Utility AI (ИИ Полезности)

Каждое действие оценивается по числовой шкале математической функцией (Utility Curve). Выбирается действие с максимальным баллом.

  • ✔ Плавная сменяемость приоритетов
  • ✔ Основа для The Sims и стратегий
  • ✖ Сложность тонкой балансировки весов
Навигация

A* Pathfinding & NavMesh

Поиск кратчайшего пути по узлам триангулированной сетки навигации (NavMesh) с учетом эвристического расстояния.

  • ✔ Гарантия нахождения оптимального пути
  • ✔ Поддержка динамических препятствий
  • ✖ Память под навигационную сетку
Будущее

Обучение с подкреплением (RL)

Агенты (нейросети), обучающиеся методом проб и ошибок в миллионах симуляций через системы наград и штрафов (Unity ML-Agents).

  • ✔ Превосходит навыки лучших игроков
  • ✔ Тестирование баланса уровней
  • ✖ Трудно контролировать дизайнерам

2. Математика и Физика Игрового ИИ

Формулы и геометрия, на которых строится зрение, слух и передвижение персонажей.

Проверка Поля Зрения (FOV)

Использует **скалярное произведение векторов (Dot Product)** для определения, находится ли объект перед персонажем в пределах угла обзора.

cos(θ) = (Forward · TargetDir) / (|Forward| * |TargetDir|)
If (cos(θ) >= cos(FOV / 2)) => Объект в конусе зрения!

После совпадения угла выполняется Raycast для проверки отсутствия стен.

Рулевое Поведение (Steering Behaviors)

Алгоритмы Крейга Рейнольдса для создания плавного и физически корректного перемещения NPC.

Desired_Velocity = Normalize(Target_Pos - Current_Pos) * Max_Speed
Steering_Force = Desired_Velocity - Current_Velocity

Применяется в задачах Seek (Преследование), Flee (Побег) и Arrive (Прибытие).

Карты Влияния (Influence Maps)

Двухмерная сетка, где каждая ячейка содержит значение threat/control. Позволяет ботам оценить безопасность укрытий.

Influence = Base_Threat / (1 + Distance * Decay_Factor)

Используется тактическим ИИ в RTS и шутерах для фланговых обходов.

3. Практический Код для Разработчиков

Готовые шаблоны кода на C# (Unity) и C++ для применения паттернов на практике.

using UnityEngine;

// Интерфейс состояния FSM
public interface IState {
    void Enter();
    void Execute();
    void Exit();
}

public class GuardFSM : MonoBehaviour {
    private IState currentState;

    public PatrolState patrolState = new PatrolState();
    public AttackState attackState = new AttackState();

    void Start() {
        ChangeState(patrolState);
    }

    void Update() {
        if (currentState != null) {
            currentState.Execute();
        }
    }

    public void ChangeState(IState newState) {
        if (currentState != null) currentState.Exit();
        currentState = newState;
        currentState.Enter();
    }
}
#include <vector>
#include <memory>

enum class NodeState { SUCCESS, FAILURE, RUNNING };

class BTNode {
public:
    virtual ~BTNode() = default;
    virtual NodeState Evaluate() = 0;
};

// Узел Селектор (Selector Node)
class Selector : public BTNode {
private:
    std::vector<std::shared_ptr<BTNode>> children;
public:
    void AddChild(std::shared_ptr<BTNode> child) { children.push_back(child); }

    NodeState Evaluate() override {
        for (auto& child : children) {
            NodeState state = child->Evaluate();
            if (state != NodeState::FAILURE) return state;
        }
        return NodeState::FAILURE;
    }
};
using UnityEngine;

public class PerceptionSystem : MonoBehaviour {
    public Transform target;
    public float viewRadius = 15f;
    public float viewAngle = 90f;
    public LayerMask obstacleMask;

    public bool CanSeeTarget() {
        Vector3 dirToTarget = (target.position - transform.position).normalized;
        float dstToTarget = Vector3.Distance(transform.position, target.position);

        if (dstToTarget <= viewRadius) {
            // Скалярное произведение для угла обзора
            if (Vector3.Angle(transform.forward, dirToTarget) < viewAngle / 2f) {
                // Проверка препятствий (Raycast)
                if (!Physics.Raycast(transform.position, dirToTarget, dstToTarget, obstacleMask)) {
                    return true; // Враг замечен!
                }
            }
        }
        return false;
    }
}
// Расчет эвристики Манхэттена для сетки
public int GetManhattanDistance(Vector2Int a, Vector2Int b) {
    return Mathf.Abs(a.x - b.x) + Mathf.Abs(a.y - b.y);
}

// Формула расчета полной стоимости F = G + H
// G = стоимость пути от стартовой ячейки
// H = эвристическая оценка до цели
public void EvaluateNode(Node current, Node neighbor, Node target) {
    int newG = current.gCost + GetDistance(current, neighbor);
    if (newG < neighbor.gCost) {
        neighbor.parent = current;
        neighbor.gCost = newG;
        neighbor.hCost = GetManhattanDistance(neighbor.position, target.position);
    }
}

4. ИИ в Легендарных Играх

Технологические революции, совершённые геймдевом благодаря алгоритмам ИИ.

F.E.A.R. (2005)

Шутер от первого лица • Monolith Productions

Первое массовое внедрение системы **GOAP**. Клоны-враги анализировали укрытия, выбивали двери, переговаривались и окружали игрока без жестких скриптов.

💡 Техника: Динамический поиск действий в пространстве состояний и глобальная доска обмена информацией (Blackboard).

Alien: Isolation (2014)

Survival Horror • Creative Assembly

ИИ Ксеноморфа состоит из двух систем: **Director AI** (знает положение игрока и дает намеки) и **Alien AI** (управляет Чужим через органы чувств и ветки Дерева Поведения).

💡 Техника: Двухуровневая архитектура и разблокировка новых узлов BT по мере игры.

Left 4 Dead (2008)

Кооперативный шутер • Valve

Система **AI Director** рассчитывает метрики стресса и здоровья игроков, динамически регулируя спавн орды, музыку, аптечки и спец-инфицированных.

💡 Техника: Процедурный контроль эмоционального темпа (Dynamic Pacing Engine).

The Sims 4

Симулятор жизни • Maxis

Использует **Utility AI (Smart Objects)**. Объект (кровать, холодильник) сам транслирует персонажам баллы полезности для удовлетворения их текущих потребностей.

💡 Техника: Оценка действий через кривые полезности и децентрализованные умные объекты.

5. Тестирование и фиксация проблем

Проблема Причина / Предположение Исправление Результат
Сетка A* выходила за пределы экрана на смартфонах. Фиксированная ширина CSS в пикселях. Применен max-width: 450px и aspect-ratio: 1. Сетка идеально масштабируется на любом смартфоне.
Нажатия на ячейки симулятора скроллили страницу на телефоне. Стандартное поведение Touch-событий в браузере. Добавлено CSS свойство touch-action: none. Плавное рисование стен пальцем без скролла.
Отрисовка конуса зрения Canvas лагала на слабых устройствах. Частый вызов перерисовки кадров. Оптимизирована математика лучей Raycast (шаг 5 градусов). Стабильные 60 FPS в 2D симуляторе.
